# 文笔校准参考：用户手写风格建模

**来源**：《一梦浮笙》第1-2章（手写）深度分析
**用途**：续写时对照此文件，确保输出符合用户手写风格

---

## 一、核心叙事人格

### 1. 感知先行
- **特征**：先写「角色感受到什么」，再写「发生了什么」
- **示例**：「周围的一切响动都仿佛泡在水里，模糊不清、遥远而沉闷」→ 先写听觉感受，再暗示事件冲击
- **校准**：每个场景开头的前 3 句必须包含至少 1 个感官描写

### 2. 身体书写
- **特征**：情绪通过身体反应（泪水、窒息、颤抖）而非心理分析表达
- **示例**：「泪水彻底决堤，把两份报告一扔，扑到林朝雨的怀里」
- **校准**：每个情绪转折点必须有至少 1 个身体记忆载体

### 3. 精准留白
- **特征**：知道什么时候停下来，信任读者的理解力
- **示例**：「医生后面还说了什么，她已经听不清了」——省略医生的话，让读者自己补全
- **校准**：每个场景中，省略的内容应占「可写但不写」内容的 30% 以上

### 4. 锚点意识
- **特征**：每个场景都有 2-3 个强感官锚点，不会让场景飘在空中
- **示例**：「白大褂的刺目的白」「声音也像是来自水面之上」「空气中弥漫渐浓的烟味」
- **校准**：每个场景至少 3 个感官锚点，且必须包含视觉+听觉/嗅觉

### 5. 节奏敏感
- **特征**：天然的三段式（积累-爆发-余韵），情绪密集段后必有呼吸空间
- **示例**：第一章用近 20 行铺垫诊断冲击，然后用一句「朝雨，我好像要死了」引爆情绪
- **校准**：情绪密集段后必须有空白段落做情感重置

### 6. 内聚焦纪律
- **特征**：严格限制在 POV 角色的感知边界内，不越界
- **示例**：「周围的一切响动都仿佛泡在水里」——严格跟随瑶笙感知
- **校准**：每个场景中，感知越界语句数量为 0

## 二、情绪书写模式

### 2.1 情绪物理化
- **核心原则**：抽象情绪必须转化为物理现象才进入叙事
- **载体优先级**：物理动作 > 身体记忆 > 比喻
- **示例**：
  - 恐惧 → 「如一记重锤砸在心上，那一瞬好似呼吸也被夺了去」
  - 哀伤 → 「泪水彻底决堤」「被水淹没的窒息感」
  - 渴望 → 「我走进去啦」（无声音，只有念头）

### 2.2 身体记忆清单
| 情绪 | 身体记忆载体 |
|------|-------------|
| 恐惧 | 窒息、心跳加速、呼吸被夺、手心出汗 |
| 哀伤 | 泪水、颤抖、肩膀颤动、声音发颤 |
| 渴望 | 目光追随、身体前倾、攥紧、屏息 |
| 安心 | 体温（「姜离的身体很暖」）、气味（「洗衣液的碱味」）、声音（「声音温温柔柔的」） |
| 释放 | 呼吸放缓、肩膀放松、单音节对话 |

### 2.3 禁止模式
- ❌ 「她感到悲伤」（心理分析）
- ❌ 「她知道……」（解释行为原因）
- ❌ 「像一只受了伤钻回巢的幼兽」（比喻替代物理动作）

## 三、场景锚点模式

### 3.1 锚点累积节奏
1. **进入场景时**：首要感知（通常是视觉或听觉）
   - 示例：「道侧翠竹在风中不安地摇摆着」（视觉）
2. **角色行动时**：次要感知（触觉或嗅觉）
   - 示例：「空气中弥漫渐浓的烟味」（嗅觉）
3. **情绪转折点**：强化感知（与情绪绑定的感官细节）
   - 示例：「仿佛还能听见木材燃烧的噼啪声」（听觉+情绪）

### 3.2 锚点清单模板
每个场景写作前，先填写：
- 视觉锚点：____（场景中的视觉细节）
- 听觉锚点：____（场景中的声音）
- 嗅觉/触觉锚点：____（场景中的气味或触感）
- 情绪锚点：____（与情绪绑定的感官细节）

### 3.3 锚点密度标准
- **最低标准**：每场景 3 个感官锚点，且必须包含视觉+听觉/嗅觉
- **理想标准**：每场景 4+ 个感官锚点，覆盖视觉、听觉、嗅觉、触觉

## 四、省略模式

### 4.1 必须省略的内容
1. **角色听不清的内容**
   - 示例：「医生后面还说了什么，她已经听不清了」
   - 修复：用省略号或「她已经听不清了」

2. **角色记不清的内容**
   - 示例：「她不记得自己是怎么回到宿舍的」
   - 修复：用「她不记得了」或时间空白

3. **情绪爆发后的心理分析**
   - 示例：「被大脑保护机制压抑了半日的过量情绪终于爆发」
   - 修复：用物理动作替代（「泪水彻底决堤，把两份报告一扔」）

4. **事件的原因/解释**
   - 示例：「许是一下午的情绪高压消耗了瑶笙本就不多的体力」
   - 修复：如果环境已经表达，删除旁白补充

### 4.2 省略判断标准
- **核心问题**：「如果删掉这句话，读者能否从上下文推断出来？」
- **如果能**：删除
- **如果不能**：保留

## 五、比喻使用模式

### 5.1 比喻优先级
1. **物理动作**（最高优先级）
   - 「泪水决堤」> 「像决堤的洪水」
2. **身体记忆**
   - 「洗衣液的碱味」> 「像家的味道」
3. **比喻**（最低优先级，仅当前两者无法表达时）
   - 「像一只受了伤钻回巢的幼兽」→ 改为：「小声的、闷在衣襟上的啜泣」

### 5.2 比喻密度标准
- **最高限制**：每场景 ≤ 2 个比喻
- **理想标准**：每 1000 字 ≤ 1 个比喻
- **续写要求**：AI 擅长生成比喻，但用户手写风格更依赖物理动作——续写时必须克制比喻的使用

### 5.3 比喻替代检查
对每个比喻，自问：
1. 「能否用物理动作替代？」
2. 「能否用身体记忆替代？」
3. 「如果都不能，这个比喻是否必要？」

## 六、节奏模式

### 6.1 三段式节奏
- **积累**：缓慢推进，逐步累积情绪/信息
- **爆发**：情绪/情节的高潮点
- **余韵**：爆发后的情感重置，空白段落

### 6.2 呼吸感
- **情绪密集段后**：必须有空白段落做情感重置
- **示例**：「瑶笙躺在林朝雨的怀里，就这么睡了过去。」之后的静默

### 6.3 时间感知
- **特征**：用身体感受替代时钟
- **示例**：「六小时前」（明确但不机械）、「数分钟后」（模糊但真实）

## 七、校准清单（续写时逐项检查）

### 7.1 感知检查
- [ ] 场景开头前 3 句是否有感官描写？
- [ ] 是否严格限制在 POV 角色的感知边界内？
- [ ] 是否有感知越界（「看到/听到/闻到/感觉到」不该感知的东西）？

### 7.2 情绪检查
- [ ] 每个情绪转折点是否有身体记忆载体？
- [ ] 是否有心理分析（「她知道/明白/理解/意识到/想到」）？
- [ ] 情绪密集段后是否有空白段落做情感重置？

### 7.3 锚点检查
- [ ] 每个场景是否有 ≥3 个感官锚点？
- [ ] 锚点是否包含视觉+听觉/嗅觉（不能全是视觉）？
- [ ] 锚点是否逐步累积（而非一次性给出）？

### 7.4 省略检查
- [ ] 是否有「解释环境已经表达的东西」的旁白？
- [ ] 是否有情绪爆发后的心理分析？
- [ ] 是否有角色听不清/记不清的内容被写出？

### 7.5 比喻检查
- [ ] 每个场景比喻数量是否 ≤ 2 个？
- [ ] 每 1000 字比喻数量是否 ≤ 1 个？
- [ ] 每个比喻是否可以用物理动作替代？

### 7.6 节奏检查
- [ ] 是否有三段式节奏（积累-爆发-余韵）？
- [ ] 情绪密集段后是否有空白段落？
- [ ] 时间感知是否用身体感受替代时钟？

## 八、违规修复示例

### 8.1 感知越界
- **违规**：「师父不会因为任何事停下来」（林朝雨的判断，不是事实）
- **修复**：「在林朝雨眼中，师父不会因为任何事停下来」或改为物理描写

### 8.2 心理分析
- **违规**：「她在孤儿院见过太多生死——先天的、后天的、送进来时已经太晚的。她知道什么时候该全力争取，什么时候该接受。」
- **修复**：用物理动作/对话/留白替代，如：「姜离没有说『会好的』，没有说『一定有办法』。她只是把瑶笙抱得更紧了一点。」

### 8.3 比喻滥用
- **违规**：「像一只受了伤钻回巢的幼兽」
- **修复**：「小声的、闷在姜离衣襟上的啜泣」

### 8.4 锚点不足
- **违规**：「院墙上的苔痕已经很老了。」（只有 1 个视觉锚点）
- **修复**：「院墙上的苔痕已经很老了。空气里有潮湿的泥土味。远处传来几声鸟叫。」

### 8.5 省略不足
- **违规**：「她在孤儿院见过太多生死——先天的、后天的、送进来时已经太晚的。」（解释背景）
- **修复**：删除，让读者从「她没有说『会好的』」推断出她的经历
