# 原作角色体系化研究

> 适用于同人创作前对原作角色进行系统性人格建模 —— 从原作文本/游戏剧本出发，
> 建立跨路线/跨时间线的完整角色模型，再投射 OC 介入后的偏移路径。

---

## 一、资料来源

### 1.1 视觉小说/游戏剧本

最高优先级的信源。角色最原始、最完整的性格表现存储在游戏剧本中。

**Fate/stay night 剧本源**：LPArchive（Let's Play Archive）
- URL: `https://lparchive.org/Fatestay-night/`
- 格式：完整英文翻译剧本，按 Fate / UBW / Heaven's Feel 三条路线组织，每天一个或多个 Update
- 每条 Update 包含完整的角色对话、内心独白、旁白描写
- 覆盖三条路线的全部分支和结局

### 1.2 其他可靠信源

| 信源类型 | 示例 | 优先级 |
|---------|------|-------|
| 官方设定集 | FSN Complete Material、动画公式书 | 高 |
| 角色百科 | TYPE-MOON Wiki、Fate Wiki | 中（需交叉验证） |
| 攻略+剧情梗概 | 各攻略站路线摘要 | 中（辅助定位场景） |
| 第三方角色分析 | Beast's Lair 讨论、红迪分析帖 | 低（仅作视角参考） |

### 1.3 LPArchive 使用指南

```
主页面：https://lparchive.org/Fatestay-night/
目录结构：
├── Prologue           序章（3天）
├── Fate               Saber线
│   ├── Day 1-16       每日细分章节
│   └── 各结局
├── Unlimited Blade Works   凛线
│   ├── Day 1-16
│   └── 各结局
└── Heaven's Feel     樱线
    ├── Day 1-16
    └── 各结局
```

使用方式：
1. 定位目标角色在该路线中的关键场景（初登场、核心冲突、转折点、结局）
2. 提取角色对话、内心独白（monologue）、其他角色对其评价的原文
3. 同一角色在不同路线中的表现需分别记录

## 二、角色建模结构

每个角色的完整模型应包含以下层次。按顺序完成。

### 2.1 基础设定

| 字段 | 说明 |
|------|------|
| 身份/称号 | 本名、职阶、在故事中的社会身份 |
| 核心关键词 | 3-5 个最能概括该角色的词 |
| 经典台词 | 代表角色性格的 2-3 句原文 |

### 2.2 性格三层模型（从文本导出）

| 层次 | 定义 | 文本依据要求 |
|------|------|-------------|
| **表层** | 角色对外展示的形象 | 必须有对话或旁白文本佐证 |
| **中层** | 角色真实的思维模式和驱动力 | 必须有内心独白或关键行为文本佐证 |
| **深层** | 角色的核心创伤/执念/未被言明的需求 | 必须有结局或关键转折文本佐证 |

### 2.3 核心法则：本质 + 环境 = 人设

**公式**：
```
人设（最终呈现） = 本质（全路线不变） + 环境（路线/剧情节点差异）
```

**本质**是角色在最底层、剥离一切外部影响后的"种子"。它在 Fate/UBW/HF 三条路线中完全相同。
**环境**包括：路线选择、关键事件、OC介入、与他人的互动结构。

**本质不变，环境变化 → 人设表现为同一角色的不同侧面。**

| 线路 | 本质（不变） | 环境（不同） | 人设（不同） |
|------|------------|------------|------------|
| Fate | 角色的核心种子 | Saber为主角的剧情结构 | 某一特定侧面暴露 |
| UBW | 同上 | 凛为主角的剧情结构 | 另一侧面暴露 |
| HF | 同上 | 樱为主角的剧情结构 | 最深层的侧面暴露 |

**应用原则**：
- 先确定本质 → 再按路线描述环境差异 → 最后推导出该路线下的人设呈现
- 角色的改变必须能从本质的"同一颗种子在不同土壤中生长"来理解
- OC 介入不改变本质，只改变环境中的一个参数（例：凛多了一个"可以被看到真实一面"的对象）
- 剧情推进也是环境变化 → 角色在同一路线内也会随剧情进展而动态变化

> **示例：间桐樱**
> - 本质：「被夺走了一切但仍然渴望被爱——即使不知道自己是否配得上」
> - Fate线环境：士郎选择了Saber，樱退为配角 → 人设：「安静地守望」
> - UBW线环境：士郎选择了凛，樱的旁观者位置固定 → 人设：「沉默的背影」
> - HF线环境：士郎选择救她，她的存在被肯定 → 人设：「从压抑到爆发的重生」

### 2.4 跨路线对比表

| 维度 | Fate 线 | UBW 线 | HF 线 |
|------|---------|--------|-------|
| 在该线中的角色定位 | 保护者/敌人/旁观者/... | | |
| 关键性格表现差异 | 该线特有的性格侧面 | | |
| 该线结局状态 | 生存/死亡/转变 | | |
| 与其他角色的核心关系 | 和士郎/凛/其他关键角色的互动定位 | | |

### 2.5 说话风格与 OOC 红线

- **OOC 红线（不可做）**：角色绝对不可能出现的言行
- **可探索边界（有文本依据的可变区域）**：角色在特定条件下可能的性格延伸
- **说话风格标签**：句式长度、语气助词偏好、语速、礼貌程度

### 2.6 与 OC 互动的适应性修正

按 OC 介入的深入程度分层投射：

| 阶段 | OC 介入程度 | 角色可能的反应/偏移 | 文本依据 |
|------|------------|-------------------|---------|
| **初始** | OC 刚出现，角色未意识到其异常 | 按原作性格对 OC 做常规判断 | 引用原作同类场景的反应模式 |
| **认知** | 角色发现 OC 力量/身份异常 | 产生好奇/警惕/研究兴趣/漠视 | 引用原作角色对异常的反应 |
| **互动** | OC 与角色产生实质性互动 | 关系的建立或冲突 | 引用原作角色对同类人物建立关系的方式 |
| **深层偏移** | OC 影响角色核心走向 | 路线选择/性格/结局的变化 | 引用原作角色在类似情境下的选择逻辑 |

**重要原则**：
- 角色的改变必须能从原作的性格逻辑中推导出来
- OC 是催化剂，不是改写器 —— 角色仍然是她自己
- 偏移路径应标注「原作文本依据」，而非凭空假设

## 三、工作流程

### Phase 1：资料采集（并行）

对每个目标角色：
1. 在 LPArchive 中搜索该角色的关键场景（按路线分别定位）
2. 提取对话、独白、旁白原文（标注 Update 编号以便回溯）
3. 从官方设定集补充角色基本参数

### Phase 2：基础建模

按上述 2.1-2.6 的结构，逐角色撰写基础人格模型。
此时不做 OC 投射，只做原作还原。

### Phase 3：OC 影响分析

1. 确定 OC 在本作中的影响力半径（直接互动角色 vs 间接影响角色）
2. 按阶段（初始→认知→互动→深层偏移）逐角色分析
3. 标注每条偏移路径的原文依据

### Phase 4：输出整合

每角色输出一份独立文档，包含 Phase 2 + Phase 3 的全部内容。
命名格式：`角色设定/人物名称-人格模型与OC偏移.md`

## 四、常见陷阱

| 陷阱 | 说明 | 应对 |
|------|------|------|
| 凭记忆写角色 | 以为自己很了解角色，实际是动画/二创的混合印象 | 必须引用原文文本作为每一个性格判断的支撑 |
| 用一条路线覆盖全角色 | 角色在不同路线中可以展现完全不同的侧面 | 必须逐路线分析，标注哪些性格跨路线稳定、哪些路线特有 |
| OC 影响过度扩张 | 让 OC 改变了不该改变的角色核心 | 标注「不可触发的改变」：角色绝不会因 OC 改变的底线性格 |
| 忽略角色的叙事功能 | 角色不仅是"一个人"，还在故事中承担特定叙事功能 | 标注角色在故事结构中的功能（英雄/导师/阴影/信使等） |
| 对话风格脱离日式语境 | 英文剧本翻译后丢失了日语敬语/语气词的层次感 | 关注角色对不同人的称呼变化（さん/ちゃん/呼び捨て）和语气词差异 |
